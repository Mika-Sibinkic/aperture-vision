# PWA icons

Pre-generated. Regenerate any time with:

```bash
python3 ../../scripts/generate-icons.py
```

- `icon-192.png` (192×192, PWA manifest)
- `icon-512.png` (512×512, PWA manifest)
- `apple-touch-icon.png` (180×180, iOS home screen)

Design: dark square + accent-green aperture ring + white center dot. Edit
`scripts/generate-icons.py` to restyle.
