# Aperture: completion checklist

What's built vs what requires external credentials you'll paste in (⇨).
The goal: you touch only ⇨ rows and then deploy.

## Built

- PWA frontend: Next.js 16 App Router, TypeScript strict, iPad Add-to-
  Home-Screen manifest, dark high-contrast UI, service worker with shell
  caching and network-only `/api/`
- Serverless relay: `/api/donate` with shared-token auth, 45s timeout,
  typed error shaping
- PWA icons: 192, 512, and 180 PNGs generated via stdlib (no PIL dep)
- n8n workflow JSON: 14 nodes, complete: webhook → token verify → prompt
  loader (full prompt embedded) → camera snapshot (digest auth) → bias-table
  fetch → OpenAI gpt-4o vision → parse + apply per-class multiplier →
  inside-zone guard → Farmbrite write OR skip path → respond
- Vision prompt v0.1: ChArUco-calibrated, JSON-only output schema,
  fallback scale logic, hidden-weight eval mode
- Phase 2 training loop: production scraper (Open Food Facts + Farmbrite
  with endpoint probing), evaluator (OpenAI + Anthropic adapters),
  bias-table builder (statistical aggregation + 20% clamp anti-hallucination),
  hidden-weight unit test (passing), cron orchestrator
- Bootstrap scripts:
  - `setup.sh`: one-command install/link/env/build/deploy
  - `smoke-test.sh`: pre-install end-to-end verification
  - `discover-farmbrite-endpoint.sh`: probes 7×3 combinations of endpoint×auth
  - `deploy-tunnel.sh`: Cloudflare Tunnel bootstrap with credentials export
- Camera-access playbook: 4 options documented with on-site decision matrix
- Deployment playbook: 6-phase install day protocol
- Updated BOM: reconciled with hardware actually purchased
- Build verified: `next build` passes TypeScript + static generation
- Unit tests passing: `test_hidden_weight.py` proves no weight leakage

## ⇨ You paste these during Phase 0 (night before) or Phase 2/3 (at Cul2vate)

All slots marked with `⇨` in `.env.example`. Concretely:

| Slot | Lives in | Filled by | When |
|---|---|---|---|
| `N8N_WEBHOOK_URL` | Vercel env | n8n workflow's Production URL after activation | Phase 0 |
| `APERTURE_SHARED_TOKEN` | Vercel + n8n (same value) | `setup.sh` mints it | Phase 0 (auto) |
| `NEXT_PUBLIC_LOCATION_LABEL` | Vercel env | you (defaults to Cul2vate, Ellington Ag Center) | Phase 0 |
| `BIAS_TABLE_URL` | n8n env | Vercel URL + `/bias-table.json` | Phase 0 after deploy |
| `HIKVISION_CAMERA_URL` | n8n env | Output of `deploy-tunnel.sh` | Phase 0 or Phase 2 |
| Hikvision u/p | n8n Credentials (Digest Auth) | Camera first-boot wizard | Phase 2 at Cul2vate |
| `FARMBRITE_API_BASE` + endpoint + header | n8n env + Credentials | `discover-farmbrite-endpoint.sh` output | Phase 3 at Cul2vate |
| OpenAI API key | n8n Credentials | Your OpenAI dashboard | Phase 0 |

## If you want zero-paste

- Stand up OpenAI key in OS keychain + export in shell → `setup.sh` can push
  it to Vercel secrets automatically (add the env key name to the `case`
  block in `setup.sh`; intentionally left OUT for safety).
- Farmbrite auto-provisioning isn't possible; API keys must be generated by
  a human in the Farmbrite UI.

## Verification before driving up

```bash
cd aperture
./scripts/setup.sh                         # deploys a working PWA shell
./scripts/smoke-test.sh <vercel-url>       # verifies PWA + bias-table
python3 training-loop/test_hidden_weight.py  # proves RL loop integrity
```

If all three exit 0, you're cleared to drive.
